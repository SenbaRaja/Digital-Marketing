# Senbagam Raja — Digital Marketing Portfolio

A responsive, dark-theme portfolio website.

## Preview locally
1. Extract this ZIP.
2. Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `senbaraja-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish. Your website address will be:
   `https://senbaraja.github.io/senbaraja-portfolio/`

The email contact button is set to: senbaraja05@gmail.com
